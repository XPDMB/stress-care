# Stress Care

เว็บแอปดูแลใจแบบ mobile-first ภาษาไทย  
สโลแกน: **Take care of your mind**

## ทดลองใช้งาน

เปิดผ่าน GitHub Pages: https://xpdmb.github.io/stress-care/

## เพิ่มลงหน้าจอโทรศัพท์

### iPhone / iPad
1. เปิดลิงก์ด้วย Safari
2. แตะปุ่ม Share
3. เลือก **Add to Home Screen / เพิ่มไปยังหน้าจอโฮม**

### Android
1. เปิดลิงก์ด้วย Chrome
2. แตะเมนู ⋮
3. เลือก **Add to Home screen / เพิ่มไปยังหน้าจอหลัก**

## ข้อมูลผู้ใช้

ข้อมูลอารมณ์และ Mood Journal เก็บใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง ไม่ถูกอัปโหลดขึ้น GitHub

> Stress Care เป็นเครื่องมือดูแลใจเบื้องต้น ไม่ใช่การวินิจฉัยหรือการรักษาทางการแพทย์
